Copy this file to `content/writings/<slug>.<en|ko>.mdx`, set `published: true`, and write. Add the other locale as a second file with the same slug to make the post switchable; a post with one file is shown under both locales with a note.

Keep this template in place: Turbopack resolves the MDX imports in
`src/lib/content/writings.ts` through a directory context, and the production
build fails to resolve the directory when it contains no MDX file at all. The
loader ignores files that do not match `<slug>.<locale>.mdx`.
