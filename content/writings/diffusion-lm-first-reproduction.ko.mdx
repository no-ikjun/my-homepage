Real-Lab에서 처음 받은 과제는 새 아이디어가 아니라 재현이었습니다. 최근 마스크 기반 diffusion 언어 모델 하나를 골라 논문의 수치를 다시 내보는 것. 결과만 보면 단순한 일인데, 논문에 적히지 않은 결정이 생각보다 많았고 그 결정 하나하나가 수치를 흔들었습니다.

## Diffusion LM이 다른 점

자기회귀 모델은 왼쪽에서 오른쪽으로 토큰을 하나씩 뽑습니다. 마스크 기반 diffusion LM은 문장 전체를 마스크로 시작해서, 여러 단계에 걸쳐 일부 위치의 마스크를 실제 토큰으로 바꿔 나갑니다. 학습은 반대 방향입니다. 정답 문장의 일부를 확률적으로 마스크한 뒤, 가려진 자리를 맞추도록 모델을 훈련합니다.

핵심 하이퍼파라미터는 두 가지였습니다.

- **마스크 비율 스케줄**: 학습 때 어느 정도를 가릴지, 그 비율을 어떤 분포에서 뽑을지.
- **디코딩 단계 수와 순서**: 추론 때 몇 단계로 나눌지, 각 단계에서 어떤 위치를 먼저 확정할지.

## 논문에 없던 결정들

### 마스크 비율을 어디서 뽑나

논문은 "균일 분포"라고만 적혀 있었습니다. 구간을 (0, 1]로 잡느냐 [0, 1]로 잡느냐, 배치마다 하나를 뽑느냐 샘플마다 뽑느냐에 따라 초반 손실 곡선이 눈에 띄게 달랐습니다. 샘플마다 뽑는 쪽이 안정적이었고, 결국 공개된 구현을 뒤져 같은 선택인 것을 확인했습니다.

```python
def sample_mask(tokens: torch.Tensor, eps: float = 1e-3) -> torch.Tensor:
    # 샘플마다 마스크 비율 t ~ U(eps, 1)을 뽑고, 위치별로 독립적으로 가린다.
    b, n = tokens.shape
    t = torch.rand(b, device=tokens.device) * (1 - eps) + eps
    return torch.rand(b, n, device=tokens.device) < t[:, None]
```

### 손실의 가중치

가려진 토큰의 교차 엔트로피를 그냥 평균 내면 마스크 비율이 작은 샘플이 과소평가됩니다. 논문의 유도식을 따라가면 손실에 `1 / t` 가중치가 붙는데, 본문에는 최종 식만 있고 이 가중치가 구현에서 어떻게 정규화되는지는 없었습니다. 가중치를 빼면 perplexity가 약 8% 나빠졌습니다.

### 디코딩에서 무엇을 먼저 확정하나

| 전략          | 설명                               | 결과                 |
| ------------- | ---------------------------------- | -------------------- |
| 무작위        | 매 단계 임의의 위치를 확정         | 기준선               |
| 확신도 우선   | 예측 확률이 높은 위치부터 확정     | 품질 개선, 반복 증가 |
| 확신도 + 온도 | 확신도에 노이즈를 섞어 순서를 흔듦 | 가장 균형이 좋았음   |

논문의 수치는 세 번째 전략에 가장 가까웠습니다. 표에는 "confidence-based"라고만 적혀 있었습니다.

## 재현하면서 만든 습관

1. 논문의 표를 그대로 옮긴 스프레드시트를 먼저 만들고, 내 수치를 옆 칸에 채웁니다. 차이가 어디서 나는지 한눈에 보입니다.
2. 하이퍼파라미터가 아니라 "논문에 없는 결정"을 따로 목록으로 적습니다. 나중에 남에게 설명할 때 이 목록이 가장 유용했습니다.
3. 작은 모델로 먼저 전체 파이프라인을 끝까지 돌립니다. 큰 모델에서 며칠 뒤에 발견할 버그를 몇 분 만에 잡을 수 있습니다.

> 재현은 논문을 읽는 가장 정직한 방법이었습니다. 읽을 때는 이해했다고 느낀 부분이 구현할 때 비어 있었습니다.
